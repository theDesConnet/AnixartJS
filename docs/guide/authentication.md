# Авторизация

Токен передаётся клиенту через параметр `token`. Для запросов с авторизацией Anixart
HTTP-клиент добавляет его в query. Не нужно самостоятельно дописывать токен в URL.

## Переменная окружения

В PowerShell перед запуском своего скрипта:

```powershell
$env:ANIXART_TOKEN = "YOUR_ANIXART_TOKEN"
```

В своём приложении после [установки пакета](./getting-started):

```js
const { Anixart } = require("anixartjs");

const token = process.env.ANIXART_TOKEN;

if (!token) {
  throw new Error("Задайте переменную окружения ANIXART_TOKEN");
}

const client = new Anixart({ token });
```

## Обновление токена

```js
client.setToken(process.env.ANIXART_TOKEN);
```

Передача `undefined` удаляет токен из клиента, но не отзывает его на сервере.

::: warning Секреты и логи
Не сохраняйте настоящий токен в документации, Git или скриншотах.
:::

## Особые случаи

Не все методы требуют авторизацию. Методы загрузки медиа могут принимать отдельный
медиатокен — это не замена токену аккаунта. Сверяйтесь с сигнатурой конкретного метода.
