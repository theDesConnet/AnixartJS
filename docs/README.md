# Сайт документации AnixartJS

Шаблон VitePress находится внутри репозитория библиотеки, но имеет отдельные зависимости.
Исходный код SDK и его конфигурацию TypeScript менять не требуется.

Для сайта нужен Node.js 22 или новее. Используется закреплённая предварительная версия
VitePress 2.0.0-alpha.20: у стабильной 1.6.4 аудит выявил уязвимости инструментов разработки.
Обновления VitePress проверяйте отдельной сборкой перед принятием.

## Запуск из корня репозитория

```sh
npm --prefix docs install
npm --prefix docs run dev
```

## Проверка production-сборки

```sh
npm --prefix docs run build
npm --prefix docs run preview
```

Результат: `docs/.vitepress/dist/`. Папки сборки, кеша и зависимостей игнорируются Git.
Зафиксируйте `docs/package-lock.json` после установки; в CI используйте `npm --prefix docs ci`.

## Адрес сайта

По умолчанию сайт работает от корня домена. Для GitHub Pages репозитория в PowerShell:

```powershell
$env:DOCS_BASE = "/AnixartJS/"
npm --prefix docs run build
npm --prefix docs run preview
```

Замените `AnixartJS` на точное имя репозитория. Для отдельного домена используйте `/`.
Значение должно совпадать при сборке и предварительном просмотре.

Шаблон не публикует сайт автоматически. Инструкция по подключению GitHub Pages:
https://vitepress.dev/guide/deploy#github-pages

## Настройка

- `.vitepress/config.mjs` — название, меню, русский поиск и базовый путь.
- `.vitepress/theme/style.css` — цвета светлой и тёмной темы.
- `index.md` — главная страница.
- `guide/` — руководства.
- `examples/` — примеры.
- `reference/` — обзор SDK и автоматически генерируемый справочник.
- `typedoc.json` — точки входа и настройки генерации.
- `tsconfig.typedoc.json` — отдельная конфигурация проверки исходников для TypeDoc.

Документация HTTP API Anixart ведётся отдельно.

## TypeDoc

Зависимости библиотеки в корне репозитория также должны быть установлены (`npm install`).
TypeDoc использует свой TypeScript 6 из `docs/node_modules`: TypeScript 7 проекта не меняется.

```sh
npm --prefix docs run api
```

Команды `dev` и `build` автоматически запускают генерацию через npm pre-скрипты.
При изменении исходников во время работы dev-сервера запускайте `api` повторно.
Прямой вызов VitePress без предварительной генерации на чистой копии не поддерживается.

Генератор создаёт только `docs/reference/generated/`, включая боковое меню.
Эта директория игнорируется Git. Не помещайте туда рукописные страницы.

## Оформление справочника

Русский перевод заголовков TypeDoc задан через `lang` и `locales.ru` в `typedoc.json`.
Имена классов, методов и типов не переводятся. Параметры и свойства выводятся таблицами,
сигнатуры — блоками кода. Ссылки на типы сохраняются в таблицах и описаниях.

Меняйте настройки генератора, а не Markdown в `reference/generated/`:
при следующей генерации ручные изменения в нём исчезнут.
