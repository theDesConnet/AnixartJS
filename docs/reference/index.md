# Справочник библиотеки

[Открыть классы, методы и типы](./generated/).

TypeDoc генерирует страницы из TypeScript и JSDoc текущего репозитория:
клиент, группы эндпоинтов, модели, enums и утилиты. Версия опубликованного npm-пакета
может отличаться от текущей разработки.

## Основные части

| Часть | Назначение |
| --- | --- |
| [Anixart](./client) | Создание клиента, токен и базовый URL |
| `client.endpoints` | Группы методов API |
| Модели и enums | Типы запросов, ответов и допустимых значений |
| `ArticleBuilder` | Подготовка содержимого статьи |
| Парсеры | Извлечение ссылок на видео |

## Обновление справочника

Из корня репозитория:

```sh
npm --prefix docs run api
```

Генерация также запускается автоматически перед `dev` и `build`.
После изменения JSDoc при работающем dev-сервере повторите команду генерации.

Файлы `reference/generated/` не редактируются вручную и не включаются в Git.
Настройки находятся в `docs/typedoc.json`. Руководства ведутся отдельно от генерации.

Документация HTTP API Anixart относится к отдельному проекту.

## Как читать страницу метода

Сначала показана сигнатура TypeScript, затем назначение метода, таблица параметров,
возвращаемый тип, примечания и пример. Символ `?` обозначает необязательный параметр.
`Promise<T>` означает, что после `await` вы получите значение типа `T`.

Ссылки на типы находятся в таблицах и описаниях. Сигнатура отображается единым
копируемым блоком кода, поэтому внутри неё ссылки не активны.
