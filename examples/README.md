# Примеры

После установки зависимостей выполните `npx tsc` из корня проекта:
примеры импортируют собранный пакет из `dist`.

| Файл | Что показывает |
| --- | --- |
| `signIn.js` | Вход по логину и паролю, установка токена в клиент |
| `searchReleases.js` | Поиск релизов и вывод первой страницы |
| `getProfile.js` | Профиль, таймаут, отмена через Ctrl+C, обработка ошибок |
| `getBookmarks.js` | Чтение своих закладок с пагинацией |
| `createArticle.js` | Загрузка изображения и публикация статьи |
| `linkParser.js` | Извлечение ссылок из разных источников |

## Вход в аккаунт

```powershell
$env:ANIXART_LOGIN = "ВАШ_ЛОГИН"
$env:ANIXART_PASSWORD = "ВАШ_ПАРОЛЬ"
node examples/signIn.js
```

Вход создаёт сессию. Пример получает `profileToken.token`, вызывает
`client.setToken()` и запрашивает профиль уже с авторизацией.
Пароль и токен не выводятся и не сохраняются в файлы.
Токен остаётся только в памяти этого процесса: для остальных примеров
задайте свой токен отдельно через `ANIXART_TOKEN`.

## Поиск релизов

```sh
node examples/searchReleases.js "Стальной алхимик"
```

Без аргумента используется запрос «Наруто». Выводятся ID, название,
количество серий и рейтинг. Запрашивается только первая страница (`page = 0`),
версия API задаётся явно через `options.apiVersion = 2`.

API v2 возвращает массив `releases` и связанную группу `related`, а не
`content`. Счётчика `total_count` в этом ответе нет, поэтому пример выводит
количество релизов на полученной странице, а не общее число совпадений.
Для API v1 (`apiVersion: 1`) метод возвращает `IPageableResponse<IRelease>`.

## Просмотр профиля и отмена запроса

```sh
node examples/getProfile.js 171123
```

Замените ID на нужный. Ctrl+C отменяет запрос через `AbortController`;
таймаут — 15 секунд. Пример отдельно обрабатывает ошибки Anixart, HTTP,
отмену и таймаут, не выводя полное содержимое ошибочного ответа.

Для поиска и просмотра профиля токен необязателен в примере.
Если сервис требует авторизацию или данные ограничены приватностью,
задайте `ANIXART_TOKEN`; токен не обходит ограничения доступа.

## Пагинация закладок

```powershell
$env:ANIXART_TOKEN = "ВАШ_ТОКЕН"
node examples/getBookmarks.js
```

Пример читает список `BookmarkType.Watching`, начиная со страницы 0,
с сортировкой `BookmarkSortType.NewToOldAddTime`.
Можно выбрать другой список, изменив `status` в файле.
Параметр фильтра пропускается через `undefined`, чтобы передать `options` последним.

Загрузка прекращается на пустой/последней странице или после трёх страниц:
лимит `maxPages` защищает от неограниченного количества запросов.
Закладки не добавляются и не удаляются. Таймаут каждого запроса — 15 секунд,
автоматических повторов нет.

## Создание статьи

`createArticle.js` получает токен редактора, загружает локальное изображение,
подготавливает встроенную ссылку и собирает статью через `ArticleBuilder.build()`.
Пример включает заголовок, текст, цитату, два списка, разделитель, ссылку и изображение.

Запуск из корня проекта в PowerShell:

```powershell
npx tsc
$env:ANIXART_TOKEN = "ВАШ_ТОКЕН"
$env:ANIXART_CHANNEL_ID = "ID_ВАШЕГО_КАНАЛА"
$env:ARTICLE_IMAGE = "./test.jpg"
node examples/createArticle.js --publish
```

**Флаг `--publish` разрешает загрузку изображения и настоящую публикацию.**
Без него пример только выводит инструкцию и не выполняет запросов.
Используйте свой тестовый канал с правом публикации; каждый повторный запуск
с флагом создаёт новую статью. Токен не нужно сохранять в исходниках.

В новой версии методы загрузки изображения, встраивания ссылки и создания статьи
находятся в `client.endpoints.article`. Токен редактора получается через
`client.endpoints.channel.editorAvaliable(channelId, false, false, options)`
и отличается от токена аккаунта. В `article.create()` передаётся результат
`builder.build()`, а не сам builder.

У каждого запроса таймаут 30 секунд; автоматических повторов нет.
Если после загрузки изображения возникнет ошибка, загруженный файл может остаться
на сервере. Если создание статьи завершится таймаутом, проверьте канал перед
повторным запуском: сервер мог успеть опубликовать статью.

## Парсинг ссылок

Из корня проекта после установки зависимостей:

```sh
npx tsc
node examples/linkParser.js
```

Пример поддерживает Kodik, Sibnet, AniLibria, VK Video, OK и Rutube, выводит качества, URL и типы
источников. Видео не скачивается целиком. Таймаут каждого вызова — 20 секунд;
ошибка одного источника не мешает проверить остальные.

При необходимости замените ссылки в массиве `examples` на актуальные.
Ссылки источников могут истекать или зависеть от IP и заголовков запроса.
Для Sibnet используется адрес плеера без фрагментов HTML и старых параметров подписи.

Для Rutube задайте свою ссылку плеера через переменную окружения `RUTUBE_URL`
или непосредственно в массиве `examples`. Без ссылки этот источник пропускается.
Пример для PowerShell (замените `VIDEO_ID` на ID видео):

```powershell
$env:RUTUBE_URL = "https://rutube.ru/play/embed/VIDEO_ID/"
node examples/linkParser.js
```

Для воспроизведения ссылок OK может потребоваться тот же User-Agent, который
используется в `OKParser`; пример только извлекает и выводит ссылки.

У всех парсеров метод называется `getDirectLinks()`. Результат — объект вида
`{ "720": [{ src, type }] }` либо `null`, а не объект с полем `files`.
Ключ `unknown` означает, что качество не определено.
